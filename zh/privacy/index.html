🛡️ 隐私政策 (Privacy Policy)

生效日期：2026年9月11日

ToolNexus 极为重视您的隐私。本隐私权政策详述了我们如何保护您的个人数据、说明纯客户端运行技术机制，以及第三方服务（包括 Google 广告系统）的 Cookie 使用合规条款。

核心隐私承诺：ToolNexus 是一家 100% 浏览器客户端驱动的工具平台。您在本站处理的所有文件（PDF、图片、合同、身份证照、文本、代码、密码、密钥）全部在您本地电脑或手机的浏览器内存中完成运算，绝不会上传至任何云端服务器，我们没有任何数据库留存您的隐私数据。

1. 我们不收集的文件与业务数据

与传统的云端转换工具不同，ToolNexus 坚决摒弃了“先上传、云端转码、再下载”的落后模式。我们通过 HTML5、WebAssembly、Canvas 2D 与 Web Crypto API 等现代前端标准在您的设备内部完成所有计算：

  • PDF 与文档处理：PDF 合并、拆分、压缩、图片互转，全程由本地 JavaScript 引擎在沙箱中重构，无网络上传；
  • 图片转换与压缩：图片格式转换、画质压缩、证件防盗水印，全部在本地 HTML5 Canvas 画布中渲染；
  • 安全与密码工具：强密码生成使用浏览器原生随机发生器，哈希计算、Base64 编解码、JWT 令牌解析均在本地完成，绝不上报密钥与 Token。

2. 第三方广告服务与 Cookie 政策（Google AdSense 条款）

为了支持本站的持续免费运营与服务器域名维护，本网站可能会接入经认可的第三方广告联盟，包括 Google AdSense。根据 Google 的官方规范与国际隐私标准，特向您说明以下内容：

  • 第三方供应商与 Cookie 使用：第三方供应商（包括 Google）会根据用户之前对本网站或其他网站的访问情况，使用 Cookie 或 Web Beacons 来投放广告；
  • 针对性广告展示：Google 使用广告 Cookie（如 DoubleClick Cookie），使得 Google 及其合作伙伴能够根据用户对本网站和/或互联网上其他网站的访问记录，向用户投放相关的商业广告；
  • 用户停用权利（选择权）：用户可以随时通过访问 Google 广告设置 (Google Ads Settings)，停用针对个性化广告的投放。或者，用户可以访问 aboutads.info，自由停用任何第三方供应商投放个性化广告所使用的 Cookie。

3. 网站日志与匿名流量统计分析

像大多数网络服务一样，我们的 CDN 托管网络（如 Cloudflare）或网站分析工具（如 Google Analytics）可能会自动收集某些非个人身份识别的常规网络日志。这些信息包括：

  • 访问时间、访问的页面 URL、引荐来源网址（Referrer）；
  • 浏览器类型、操作系统类型与首选语言；
  • 匿名化的 IP 地址（用于粗略识别访问国家/地区以优化 CDN 加速路由）。

此类数据纯粹用于维护网站正常运行、统计各工具的受欢迎程度以指导产品改进，绝对不会与您的个人真实身份相关联。

4. 本地存储 (Local Storage) 的使用

本站仅在您的浏览器 localStorage 中存储极少量不包含任何个人隐私的功能性偏好设置：

  • 网站明暗主题：记录您选择的是“暗黑模式”还是“明亮模式”（键名：tool_nexus_theme）；
  • 所有存储均保留在您的浏览器本地，您可随时在浏览器设置中清空网站缓存。

5. 儿童隐私保护 (COPPA)

本站不面向 13 岁以下的儿童。我们不会有意收集或索取 13 岁以下未成年人的个人可识别信息。若您发现有未成年人向本站提供了个人信息，请通过下方的联络渠道通知我们，我们将立即核查并予以清除。

6. 欧盟 GDPR 与加州 CCPA 权利合规

根据欧洲通用数据保护条例 (GDPR) 与加州消费者隐私法 (CCPA)，用户拥有对个人数据的知情权、访问权、更正权、删除权及拒绝数据出售的权利。由于 ToolNexus 从不在服务端存储您的文件或个人画像，本站不向任何第三方出售、出租或交易用户的个人数据。
