深入理解密码学散列函数 (Hash) 与文件完整性校验

密码学散列函数（Cryptographic Hash Function）是一种将任意长度的二进制输入映射转换为固定位宽输出序列的单向数学运算。所生成的输出字符串被称为消息摘要（Digest）或哈希校验和（Checksum）。在现代信息安全、分布式网络与软件工程中，哈希算法是数字签名、TLS/SSL 传输加密证书、Git 分支版本追踪、区块链（如比特币工作量证明）以及密码安全存储的技术底座。

合格的密码学散列算法必须满足三大安全特征： 抗原像性（Pre-image Resistance，不可逆性）：已知摘要值无法倒推原始输入； 抗第二原像性（Second Pre-image Resistance）：给定输入无法找到另一具有相同摘要的输入； 抗碰撞性（Collision Resistance）：无法在计算可行时间内找出任意两个能产生相同摘要的不同数据。ToolNexus 深度调取浏览器原生硬件指令级 Web Crypto API，全程在用户终端设备内存中闭环运算。

常见主流哈希算法特性对比

算法名称 摘要长度 安全等级 适用场景与权威评级
SHA-256 256 位 (64 位 Hex) 极高（行业黄金标准） HTTPS 证书签名、开源软件包官方防篡改校验、比特币底层 PoW
SHA-512 512 位 (128 位 Hex) 军工级高安全 关键金融系统、超长寿命数据归档防篡改，在 64 位 CPU 上运算极快
SHA-1 160 位 (40 位 Hex) 已淘汰（存在碰撞攻击） 老旧系统、Git 内部对象索引（现代版本正逐步向 SHA-256 迁移）
MD5 128 位 (32 位 Hex) 已攻破（禁止用于安全验证） 仅用于检测网络下载偶发丢包、磁盘读写坏道等非恶意篡改校验

MD5 / SHA-1 的碰撞风险意味着什么？

2004 年中国密码学权威王小云团队破解了 MD5 的碰撞抵抗性，2017 年 Google 团队实施了著名的 SHAttered 攻击，成功生成了两份哈希完全相同但正文条款迥异的合法 PDF 合同。这意味着中间人攻击者可以诱骗用户签署一份正常的合法文件，随后悄无声息地替换为包含恶意代码的文件而保持签名有效。因此，现代应用开发中，所有数字签名与敏感校验必须强制使用 SHA-256 或 SHA-3。

常见问题解答 (FAQ)

Q: 哈希运算中的“雪崩效应 (Avalanche Effect)”是什么？

雪崩效应是优良散列算法的核心特征：只要输入明文改变了哪怕仅仅 1 个比特（例如仅仅改变一个标点或空格），最终输出的十六进制哈希值就会产生剧烈紊乱，通常有超过 50% 的位发生反转，完全无法预测关联性。

Q: 用户数据库密码能否直接用纯 SHA-256 保存？

绝不能。SHA-256 为高速吞吐而设计，现代高性能显卡（GPU）每秒可计算数十亿次，极易遭受彩虹表碰撞。存储用户密码必须采用耗时高、抗硬件并行的专用算法，如 bcrypt、Argon2id 或 PBKDF2。

Q: 在线计算大文件或敏感密钥时安全吗？

绝对安全。本工具纯前端运行，通过 FileReader 在浏览器本地将文件分块读取后直通 CPU Web Crypto 模块，整个流程零网络数据包外出。
