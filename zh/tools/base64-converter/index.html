Base64 相关常见疑问

为什么本工具对中文能够完美编解码而不乱码？ ▼
原生 JavaScript 的 btoa 与 atob 函数仅支持 Latin1（单字节）范围字符，遇到 UTF-8 多字节汉字或 Emoji 时会直接报错或产生乱码。本工具使用了 TextEncoder 与 TextDecoder 双向字节流转译管道，确保中文字符、特殊符号及表情包均能 100% 准确解码。
网页开发中什么时候适合把图片转成 Base64？ ▼
当图片体积非常微小（例如 5KB 以下的图标、小背景纹理、加载动图）时，将其内嵌为 Base64 Data URL 可以直接减少一次 HTTP 请求，降低网络握手耗时；但由于 Base64 会使体积增大约 33%，因此不建议将大照片嵌入为 Base64。
