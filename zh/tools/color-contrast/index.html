为什么现代产品必须遵守 WCAG 颜色无障碍标准？

根据世界卫生组织（WHO）数据，全球有超过 22 亿人患有视力障碍，其中包括广泛存在的红绿色盲、蓝黄色弱及老年性白内障弱视人群。W3C 推出的《Web 内容无障碍指南》(WCAG) 是全球各大科技企业与政府机构通行的数字包容性法案技术基准。

在欧洲无障碍法案（EAA）以及美国残疾人法案（ADA / Section 508）中，网站与移动 App 达到 WCAG 2.1 AA 级对比度是出海企业不可忽视的法律合规准则。ToolNexus 采用 CIE XYZ 国际色度学模型严格推导相对明度比值，为您提供毫秒级的专业色彩核验。

常见问题解答 (FAQ)

Q: WCAG 中对“大号文字 (Large Text)”的标准定义是什么？

大号文字是指字号达到或超过 18pt（约为 24px CSS 像素），或者字号达到 14pt 且为粗体（约为 18.66px 加粗）的文字排版。

Q: 相对明度 (Relative Luminance) 是如何计算出来的？

相对明度计算需先将 sRGB 色彩空间经过 Gamma 反校正转化为线性 RGB 分量，再按人眼对绿色、红色与蓝色敏感度权重（0.7152G + 0.2126R + 0.0722B）计算绝对明度比值。
