1. PDF 内部矢量指令到光栅位图（Rasterization）的渲染链路

PDF 本质上是一组矢量绘图指令集合，包含了贝塞尔曲线、字形轮廓（TrueType/OpenType 字体子集）、CMYK/RGB 色彩矩阵以及嵌入图像 XObject。

当 ToolNexus 执行转图时，底层 PDF.js 引擎通过 page.getViewport({ scale }) 动态计算物理视口分辨率，并在内存中调起 HTML5 CanvasRenderingContext2D 执行逐像素光栅化绘制。针对文字部分，利用字形抗锯齿平滑算法渲染出锐利边缘；针对矢量图形，自动按视口像素网格进行高保真重映射，从而生成媲美出版物级别的超清位图。

3. DPI 分辨率缩放与流式内存保护机制

PDF 标准内置以 72 pt/inch 为基础单位。ToolNexus 默认采用 scale: 1.5 视口渲染参数，等效于 108~150+ DPI 的物理清晰度，在常规高清显示屏和 Retina 视网膜屏上展现出无锯齿的印刷品质感。针对数十页的复杂文件，工具采用逐页流式渲染并即时释放非必要 DOM 节点的内存占用，最终通过 JSZip 在浏览器客户端内秒级打包归档，确保多页批量转换稳定不崩溃。

常见问题解答 (FAQ)

Q: PDF 导出为图片后，原文档中的文字还能直接复制或搜索吗？

导出后的图片属于纯光栅位图（Raster Bitmap），文字已被固化为像素网格，无法再像 PDF 那样直接鼠标划选文字。若需提取文字，可使用配套的 OCR 识别工具进行文字逆向提取，或者保留原始 PDF 文档以供编辑检索。

Q: 文档中带有透明背景的公章或签名，导出为 JPG 会变成黑底吗？

不会。JPG 格式由于天生不支持 Alpha 透明通道，ToolNexus 会在 Canvas 上自动预先填充纯白底色（#FFFFFF）进行合成，保证透明印章与公章清晰自然呈现；若您需要保留完全透明的底色，建议选择导出为 PNG 格式。

Q: 数十页的 PDF 文档批量转为图片打包，浏览器会卡死奔溃吗？

不会。ToolNexus 采用逐页异步流水线设计，每页在 Canvas 绘制完成后立即导出为低显存占用的 Blob 内存流，并主动销毁临时绘图上下文，有效防范页面 OOM 崩溃，大页数文件也能流畅转图并生成 ZIP 压缩包。

Q: 将公司的财务发票、保密合同转成图片，会不会上传到云端？

绝对零上传。ToolNexus 是 100% 纯客户端运行的 Web 应用，整个 PDF.js 解析与 Canvas 绘制全过程均在您本地设备的浏览器沙箱中执行，甚至拔掉网线或开启飞行模式也能全速转换，商业隐私绝对安全。
