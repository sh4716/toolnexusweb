关于英文排版大小写的规范与规则

Q: Title Case（标题大小写）是如何判定哪些词不该大写的？

遵循 AP（美联社）和芝加哥大学出版规范：虚词（冠词 a, an, the；并列连词 and, but, for, or, nor；短介词 in, on, at, to, by, of 等）默认保持小写，但位于标题首词或尾词时强制大写。

Q: 编程中 camelCase、snake_case 和 kebab-case 通常用在何处？

camelCase 常用于 JavaScript/Java 变量与函数名；snake_case 常用于 Python 变量及数据库字段；kebab-case 则常用于 URL Slug 和 CSS 类名。
