在数据泄露事件频发的今天，使用诸如生日、手机号、连续键盘字母（如 qwerty123）或重复口令，已成为账号遭到“撞库攻击”与彩虹表秒解的最核心根源。根据美国国家标准技术研究所（NIST SP 800-63B）的最新数字身份安全规范，防御现代黑客 GPU 暴力破解的最有效手段，就是使用高信息熵且不可预测的伪随机/真随机强密码。

密码信息熵计算公式与安全基线

在香农信息论（Information Theory）中，密码的随机强度完全取决于其信息熵（Entropy Bits）。计算公式为：

E = L × log₂(R)

其中 L 为密码长度，R 为可选字符池的大小（Pool Size）。 例如纯小写字母（R=26），16 位密码的熵约为 75 bits；而当混合大写字母、小写字母、数字及特殊符号（R=94）时，16 位密码的熵将飙升至 104.8 bits。在现代密码学中，信息熵达到 80 bits 以上即可防御绝大多数离线暴力碰撞，而超过 100 bits 则足以抵御超级计算机集群数十亿年的暴力穷举。

为什么绝不能用 Math.random()？CSPRNG 与系统熵池揭秘

绝大多数普通在线工具使用 JavaScript 的 Math.random() 来生成随机字符串，这在密码学中属于灾难性漏洞。Math.random() 是线性的伪随机数算法（如 xorshift128+），其种子状态具有高度可预测性，黑客只需捕获连续几段生成的随机数即可精确逆向算出后续所有输出。

ToolNexus 严格调用现代浏览器底层标准 window.crypto.getRandomValues()。该接口属于密码学安全伪随机数生成器（CSPRNG），随机种子直接从操作系统内核熵池采集（包括硬件中断微秒延迟、CPU 热噪声与键鼠微操抖动），具备密码学级别的单向不可逆与绝对不可预测性。

常见问题解答 (FAQ)

Q: 为什么在运维与终端中建议勾选“排除易混淆字符”？

很多等宽字体或移动端输入法中，数字 1 与小写字母 l、大写字母 I；数字 0 与大写字母 O；以及字符 ` 与 ' 极其相似，容易导致手工输入验证时频繁报错锁死账号。勾选该项可确保生成的口令在任何终端和手写便签上都绝无歧义。

Q: 复杂的 16 位强密码记不住怎么办？

人类记忆随机高熵字符极为困难且毫无必要。业界的最佳黄金实践是：由本工具生成高强度密码后，直接存储至现代密码管理器（如 1Password、Bitwarden、KeePass 或 Apple 钥匙串），日常仅需牢记一个高强度的根主口令，其余各网站全部由密码管理器自动填充，杜绝一密多用。

Q: 批量生成的 10 条密码适合用于哪些实际场景？

非常适合企业 IT 管理员批量创建新员工域账号、批量部署多台 Linux 服务器初始 root 临时口令、或为微服务群批量生成高强度的 API Token 与 JWT Secret 签名密钥。
