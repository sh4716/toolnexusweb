为什么需要 CSV 与 JSON 双向格式互转？

CSV（逗号分隔值）是全球电子表格软件（如 Microsoft Excel、WPS Office、Google Sheets）以及传统关系型数据库导出事实上的行业标准。而 JSON（JavaScript 对象表示法）则是当今互联网前后端 API 数据交互、NoSQL 数据库存储（如 MongoDB、Elasticsearch）和各类微服务通信的基础通用语言。

数据分析师、开发工程师在日常工作常常需要将业务部门提供的 Excel/CSV 报表清洗为 API 所需的 JSON 对象，或者将后端接口返回的复杂 JSON 数组转为可直接双击用表格查看的 CSV 文件。ToolNexus 提供的纯浏览器本地解析方案，从源头上杜绝了机密业务表格、财务数据或内部用户名单通过网络上传被监听或泄露的风险。

快速使用步骤指南

  1. 模式切换： 点击顶部工具栏按钮选择 CSV ➔ JSON（表格转对象数组）或 JSON ➔ CSV（对象数组平铺为表格）。
  2. 参数自定义： 勾选是否将第一行作为 Key 键名；根据需要选择字段分隔符（逗号、Tab、分号等）；设定 JSON 输出的缩进排版风格。
  3. 载入数据： 直接在左侧输入框粘贴文本，或者点击“上传文件”载入本地 .csv、.json 或 .tsv 文件。
  4. 一键导出： 右侧即时生成结构化结果，支持一键剪贴板复制或直接打包下载到本地。

常见问题解答 (FAQ)

Q: 表格里有些文本本身包含了英文逗号或换行，转换时会错列吗？

不会错列。本工具严格遵循 RFC 4180 国际标准规范，对于含有逗号或换行符的单元格内容，会自动识别双引号封闭边界并予以完整保留，绝不破坏数据对应关系。

Q: 转换有文件体积或行数上限吗？

没有云端限制。因为运算完全调用您本机设备的浏览器内存，几十兆（数万至数十万行记录）的数据通常可以在数百毫秒内毫秒级完成转换。

Q: 如果 JSON 含有深层嵌套对象，转换成 CSV 时会如何处理？

对于嵌套的子对象或子数组，工具会自动将其规范序列化为 JSON 字符串置于对应的表格单元格内，既保留了数据的完整性，又避免了表格被无规则拉裂。
