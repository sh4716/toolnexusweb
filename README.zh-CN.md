## 🌟 核心特色

- **🔒 100% 隐私安全：** 所有 PDF 处理、图片压缩与加水印、加解密运算均基于浏览器端 WebAssembly 和 JavaScript 运行，零服务端日志，保护隐私。
- **⚡ 零网络延迟：** 计算全部在本地完成，免去文件上传和下载等待，秒级即时响应。
- **🌐 原生双语支持：** 完整支持英文版与简体中文版（`/zh/`）。
- **🌓 深色模式（Dark Mode）：** 优雅的主题切换，防闪烁加载与顺滑过渡。
- **🚀 零构建依赖：** 纯原生 HTML5、CSS3 与 JavaScript 编写，无需打包编译步骤，随时随地开箱即用。

## 🚀 本地开发与运行

由于 ToolNexus 是纯静态前端项目，无需任何打包构建工具，你可以使用任何静态 Web 服务器运行：

### 方式 1：使用 Python
```bash
python -m http.server 8080
```
在浏览器中打开 [http://localhost:8080](http://localhost:8080) 即可访问。

### 方式 2：使用 Node.js
```bash
npx serve .
```

### 方式 3：使用 Cloudflare Wrangler
```bash
npx wrangler dev
```
