Frequently Asked Questions

Q: Does this handle mixed landscape and portrait pages?

Yes. The algorithm measures the exact physical width and height of each individual page dynamically, positioning the page numbers consistently regardless of orientation.

Q: Will my hyperlinks, bookmarks, or text formatting be affected?

Never. The page numbers are stamped in a non-destructive layer over the existing document, keeping all original text, vector graphics, and links intact.
